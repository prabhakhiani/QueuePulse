# QueuePulse — Cloud Workload Simulator

A browser-based educational simulation demonstrating request queues, workload scheduling, worker availability, fault scenarios, and dashboard metrics. It does not connect to or manage a real cloud platform.

## Files
- `index.html` — page structure
- `styles.css` — responsive dark navy and teal design
- `app.js` — navigation, simulation logic, metrics, event log, chart and CSV export

## Run it
1. Keep all three files in the same folder.
2. Open the folder in VS Code.
3. Open `index.html` with the Live Server extension, or double-click it to open in a browser.
4. Try **Simulation Lab** → **Start simulation**, **Step**, **Traffic spike**, **Worker failure**, **Database slowdown**, and **Recover system**.
5. Use **Export CSV** after at least one event is recorded.

Google Fonts are loaded from the internet. If offline, the page uses system fallback fonts.
